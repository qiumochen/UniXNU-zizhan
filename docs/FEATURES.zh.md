# 小米 MIX Fold 2 · iPadOS 功能适配清单

截至 **2026 年 11 月 7 日**，适配系统为 **iPadOS 18.7.10**。

目前已能在内屏进入系统、触摸操作、调节亮度和连接 Wi-Fi。完整的锁屏待机、声音、折叠切屏、通话和相机等能力仍未完成，**尚未达到日常主力机水平**。

本清单按已有真机记录整理。“已可用”表示所述功能已确认能用；“部分可用”表示已有功能，但仍有明确限制；“待确认”表示尚无充分的实际使用验证；“暂不支持”表示当前适配尚未提供这项完整能力。已有功能的长期稳定性仍需继续验证。

**系统、屏幕与操作**

| 功能 | 适配情况 | 用户可感知的表现 |
| --- | --- | --- |
| 启动进入系统 | 部分可用 | 已能进入桌面并打开应用；仍有偶发启动失败和画面异常问题，尚未完全解决。 |
| 内屏显示 | 已可用 | 能显示系统桌面和已验证应用的画面。 |
| 内屏触摸 | 已可用 | 能点击、打开应用和滑动；更多复杂手势尚未全面确认。 |
| 手动调节亮度 | 已可用 | 可以通过系统设置中的亮度滑条调整内屏亮度。 |
| 高刷新率显示 | 部分可用 | 内屏已支持以 60 Hz 或 120 Hz 启动；部分动画流畅度已有改善，尚不能保证所有应用都达到 120 帧，使用中自动切换刷新率也未确认。 |
| 自动亮度 | 暂不支持 | 尚不能根据环境光自动调节屏幕亮度。 |
| 外屏显示与触摸 | 暂不支持 | 当前适配使用内屏，外屏显示和触摸尚不可用。 |
| 折叠与内外屏切换 | 暂不支持 | 尚不能在开合手机时自动切换屏幕或接续当前应用。 |
| 电源键 | 部分可用 | 已确认长按可重启退出当前系统；短按锁屏、熄屏和唤醒仍待确认。 |
| 音量键 | 待确认 | 实际按键调节音量的效果尚未完成验证。 |

**网络与连接**

| 功能 | 适配情况 | 用户可感知的表现 |
| --- | --- | --- |
| Wi-Fi 选网与联网 | 已可用 | 可以在系统设置中选择已测试的 Wi-Fi、输入密码并联网。 |
| 记住 Wi-Fi 并自动连接 | 已可用 | 已保存的网络可以自动加入。 |
| 关闭、重新开启 Wi-Fi | 已可用 | 已确认关闭后重新开启可以再次联网。 |
| 2.4 GHz / 5 GHz Wi-Fi 切换 | 已可用 | 已测试网络的两个频段之间可以重新连接并联网；其他网络环境仍需分别确认。 |
| Wi-Fi 长时间使用 | 部分可用 | 已有约半小时的连续联网测试；全天使用、跨不同网络切换和待机后联网仍未完成验证。 |
| 更多 Wi-Fi 类型 | 待确认 | WPA3、企业认证和 6 GHz 网络尚未确认支持。 |
| 移动数据 | 暂不支持 | 尚不能使用 SIM 卡通过蜂窝网络上网。 |
| 电话与短信 | 暂不支持 | 尚不能作为正常手机拨打、接听电话或收发短信。 |
| 蓝牙及蓝牙外设 | 待确认 | 搜索、配对、蓝牙耳机和其他外设尚无充分的可用性验证。 |

**电池、待机与声音**

| 功能 | 适配情况 | 用户可感知的表现 |
| --- | --- | --- |
| 电量显示 | 已可用 | 已确认状态栏电量显示，系统可以读取实际电池信息。 |
| 充电状态显示 | 已可用 | 已确认插拔电源时充电状态会变化；快充速度和完整充放电表现仍待确认。 |
| 设置中的电池页面 | 部分可用 | 页面可以打开；电池健康页面仍会一直转圈，完整用量图表尚未确认。 |
| 完整锁屏、熄屏与唤醒 | 暂不支持 | 尚未完成整套功能适配，不能保证像正常手机一样息屏后再恢复使用。 |
| 省电待机与续航 | 待确认 | 尚未完成正常低功耗待机和续航验证。 |
| 自动温控 | 暂不支持 | 已有温度读取测试，自动控制发热尚未实现。 |
| 扬声器播放声音 | 暂不支持 | 当前尚不能通过机身扬声器正常播放声音。 |
| 麦克风与录音 | 待确认 | 尚未完成录音和语音输入适配验证。 |

**应用与其他日常功能**

| 功能 | 适配情况 | 用户可感知的表现 |
| --- | --- | --- |
| 设置、时钟、天气等系统应用 | 部分可用 | 已有打开和显示画面的记录；各应用的完整功能尚未逐项确认。 |
| 照片应用 | 部分可用 | 已能启动并进入初始界面；查看照片、相册、搜索和编辑仍待进一步确认。 |
| 浏览器上网 | 待确认 | 已确认系统可以联网，但浏览器打开网页、播放内容等实际使用仍待单独验证。 |
| 中文、英文输入 | 待确认 | 键盘输入与日常文字编辑尚未完成验证。 |
| 应用切换与多任务 | 待确认 | 多应用切换、后台恢复和多任务显示仍需完整验证。 |
| 数据保存 | 部分可用 | 系统数据区域已能读写；日常内容在重启、异常退出后的保存情况仍待完整验证。 |
| 相机、拍照与录像 | 暂不支持 | 尚未完成相机适配，不能正常拍照或录像。 |
| 动态壁纸 | 暂不支持 | 当前存在兼容限制，尚不能作为正常可用功能。 |
| Apple 账号、应用商店与第三方应用 | 待确认 | 登录、安装和各应用兼容性尚未形成完整验证结果。 |
| 消息推送与后台接收 | 待确认 | 日常使用和锁屏后的消息接收尚未完成验证。 |
| 自动旋转、定位等功能 | 待确认 | 尚无足够记录确认这些功能可以正常使用。 |
