# 小米 MIX Fold 2 · iPadOS 功能适配清单

截至 **2026 年 11 月 28 日**，适配系统为 **iPadOS 18.7.10（22H374）**，默认设备身份为 **iPad7,12**。

目前已能在内屏正常进入桌面、四向旋转、触控与中文输入、自动/手动调节真实背光亮度、使用 Adreno 730 硬件渲染与 120 Hz 零拷贝显示、连接 2.4 / 5 GHz Wi-Fi、开启 `3 Mbps` 蓝牙扫描、在 **`<1 W` 平台级深睡（`952 mW`，稳态 `730 mW`）** 下省电待机，并通过内置 **`IPA 安装器` v2** 在非破坏性 `64 GiB` 根卷（`48 GiB` Data）中流式直装已脱壳第三方应用。双扬声器/主麦/听筒/线性马达的集中主观试听、离开电脑独立启动（M3）、合盖外屏锁屏/竖屏锁止/外屏电源键及第三方相机方向色彩校正仍待在场验收或修复，蜂窝上网与原厂系统相机尚未支持，**尚未达到日常主力机水平**。

本清单按已有真机记录整理。“已可用”表示所述功能已确认能用；“部分可用”表示已有真机闭环，但仍有明确限制或待在场终验项；“待确认”表示尚无充分的实际使用验证；“暂不支持”表示当前适配尚未提供这项完整能力。

**系统、屏幕与操作**

| 功能 | 适配情况 | 用户可感知的表现 |
| --- | --- | --- |
| 启动进入系统 | 部分可用 | 通过电脑 `fastboot boot` 临时引导可稳定进入桌面，默认不写任何分区；独立双启动包（默认进 Android，菜单可选 `iPadOS 18 (zizhan)`）已通过离线与原厂备份校验，待在场 RAM 预演。 |
| 内屏显示与四向旋转 | 已可用 | 2160×1916 内屏正常显示 iPadOS 桌面、右上角电池状态栏、控制中心及应用；修复 22H374 Metal 旋转错位后支持 `0°/90°/180°/270°` 四向零拷贝显示。 |
| 内屏触摸 | 已可用 | 点击、打开应用、滑动、软键盘输入及上滑回主屏手势可用；熄屏自动停扫内屏触控省电。 |
| 手动与自动调节亮度 | 已可用 | 可通过系统亮度滑条调整真实 L18 DCS 背光亮度；本地固件存在时默认启用 SLPI 环境光自动调光与外屏夜间压暗。 |
| 高刷新率与动画流畅度 | 部分可用 | 内屏默认 120 Hz 零拷贝（6 画布槽位）并关闭内核调试追踪热点（0045），缩放动画约 58 fps、主屏落定约 95 fps；不宣称全局 120 fps，动态刷新率未实现。 |
| 外屏显示与触摸 | 部分可用 | 合盖可点亮外屏时钟并通过上滑/双击进入 `2:1` 或 `1:1` 满高（`1080×1916` + `ZOOM` 胶囊）外屏桌面，支持 ST FTM5 手指触控、底栏四胶囊与口袋近距防误触；合盖未先进锁屏且仍随重力横屏旋转、外屏按电源键无响应两项问题待修（`video-7`）。 |
| 折叠与内外屏切换 | 部分可用 | 默认结合 GPIO62 霍尔与 SLPI `hinge_angle` 铰链角度自动切换内外屏并断电未用屏幕；上述合盖锁屏与竖屏锁止细节待修。 |
| 电源键与音量键 | 部分可用 | 内屏状态下短按电源键进入/唤醒 `<1 W` 平台深睡（连续 25+ 轮零 panic），长按 3 秒热复位退出；实体音量键已加单步防连跳节流（0044）；外屏态短按电源键待修。 |

**网络与连接**

| 功能 | 适配情况 | 用户可感知的表现 |
| --- | --- | --- |
| Wi-Fi 选网与联网 | 已可用 | 可在系统设置中选择 WPA2 / 开放 Wi-Fi、保存凭据自动入网并通过 DHCP 访问 HTTPS。 |
| 2.4 / 5 GHz 切换与深睡保持 | 部分可用 | 2.4 GHz 与 5 GHz 不同 BSSID 双向重连及跨多轮 `<1 W` 平台深睡/唤醒保持关联已通过；跨不同子网、WPA3/企业网与全天漫游待验证。 |
| 蓝牙及蓝牙外设 | 部分可用 | 默认以 `3 Mbps` 高速串口开启蓝牙（`552 ms` 加载固件）并持久化配对目录，设置页面可开启蓝牙并扫描附近设备；手动配对与蓝牙音频待在场验证。 |
| 移动数据、电话与短信 | 暂不支持 | 基带锁定在离线无射频模式（零蜂窝发射）；插卡上网、电话与短信均未启用。 |

**电池、深睡、声音与触感**

| 功能 | 适配情况 | 用户可感知的表现 |
| --- | --- | --- |
| 电量、充电与电池设置页 | 已可用 | 状态栏与设置页显示真实电量、插拔状态、双电芯电压、SOH 健康度（约 80%）与循环次数，设置电池页默认采用清爽双开关布局（百分比 + 低电量模式）。 |
| 锁屏深睡与待机续航 | 已可用 | 默认开启 `IOPMrootDomain` + CPU 1–7 `CPU_OFF` + 外屏断电 + Adreno DDR 释放 + `zizhan_standby_bw=3` 总线降票，**纯电池熄屏深睡功耗降至 `-219 mA / 952 mW`（稳态底噪 `730 mW`）**。 |
| 自动温控 | 已可用 | 日用默认开启双组 TSENS 采样与逐级压频/释放（CPU 90 °C / GPU 85 °C 阈值），持续浸泡无过热重启。 |
| 扬声器、听筒与麦克风 | 部分可用 | 默认装载 CoreAudio `ZizhanAudio.driver`（双 CS35L41 外放 + `VoiceChat` 顶部 `0x40` 听筒路由 + WCD9385 物理主麦录音）；无人值守默认静音保护，在场开启 `ZIZHAN_USER_PRESENT=yes` 后待集中主观终验。 |
| 线性马达触感 | 部分可用 | 已接入 PM8350B X 轴线性马达（无人值守默认静振，在场开启），待随音频一并在场体验确认。 |

**应用、相机与其他日常功能**

| 功能 | 适配情况 | 用户可感知的表现 |
| --- | --- | --- |
| 第三方 IPA 安装与沙盒兼容 | 部分可用 | 支持非破坏性 `64 GiB` 根卷（`48 GiB` Data），主屏预置 **`IPA 安装器` v2**（网页流式直装 `<=12 GiB` 已脱壳 `4K/16K` IPA，拦截未脱壳 App Store 加密包），默认提供全局 Metal、Keychain/AppGroup 回退与 `9:16` 居中手机视口（`ZizhanCompatSuite` 8/8 通过）。 |
| 设置、备忘录、时钟、浏览器等 | 部分可用 | 设置、时钟、备忘录正常打开热启动；Safari 可浏览公网 HTTPS 网页与无 DRM 视频；默认北京时间（`Asia/Shanghai`）；天气因缺 FairPlay 仅显示城市名无预报。 |
| 中文、英文输入 | 已可用 | `iPad7,12` 身份下系统原生中英文（含拼音）软键盘可正常弹出与输入。 |
| 第三方相机（扫码与拍照） | 部分可用 | 第三方容器应用可通过 `AVCaptureSession` 调用 `960×720` 前后摄像头实时取景、切换、`DW9800V` 对焦与 `RumbaS4H` 光学防抖（退出后 `3.5 s` 零功耗断电）；**当前画面方向不对、噪点与偏色明显**（`video-7` 已记录待修），原厂系统 `Camera.app` 暂不支持。 |
| 自动旋转、传感器与 GPS | 部分可用 | 本地固件存在时默认开启 SLPI 7 传感器（加速度计/陀螺仪四向旋转、磁力计、气压计、环境光、近距与铰链角）；可选 `zizhan_gnss=2` 支持离线 1 Hz GPS 注入 `CoreLocation`（户外搜星待在场验证，默认关闭）。 |
