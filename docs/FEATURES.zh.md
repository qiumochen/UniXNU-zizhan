# 小米 MIX Fold 2 · iPadOS 功能适配清单

截至 **2026 年 11 月 24 日**，适配系统为 **iPadOS 18.7.10（22H374）**，默认设备身份为 **iPad7,12**。

目前已能在内屏正常进入桌面、触控与打字输入、调节真实背光亮度、使用 Adreno 730 硬件渲染与 120 Hz 零拷贝显示、连接 2.4 / 5 GHz Wi-Fi、开启蓝牙扫描附近设备，并在日用默认配置下完成内屏熄屏/亮屏、温控逐级压频与电量状态显示。扬声器实际出声、外屏完整界面与手指触控、离开电脑独立启动、蜂窝上网与相机成片等能力仍待在场验收或继续开发，**尚未达到日常主力机水平**。

本清单按已有真机记录整理。“已可用”表示所述功能已确认能用；“部分可用”表示已有功能或无人值守闭环，但仍有明确限制或待人工复核项；“待确认”表示尚无充分的实际使用验证；“暂不支持”表示当前适配尚未提供这项完整能力。

**系统、屏幕与操作**

| 功能 | 适配情况 | 用户可感知的表现 |
| --- | --- | --- |
| 启动进入系统 | 部分可用 | 通过电脑 `fastboot boot` 临时引导可稳定进入桌面并打开常见系统应用，每轮结束自动回 Android；离开电脑独立开机启动（M3）待在场写入验收。 |
| 内屏显示 | 已可用 | 2160×1916 内屏正常显示 iPadOS 桌面、右上角电池状态栏、控制中心及已验证应用；锁屏日期与时钟重叠已修复。 |
| 内屏触摸 | 已可用 | 点击、打开应用、滑动、软键盘输入及上滑回主屏手势可用；更多多指复杂手势待全面确认。 |
| 手动调节亮度 | 已可用 | 可通过系统设置中的亮度滑条调整内屏真实 L18 DCS 背光亮度，具备匹配回读与恢复验证。 |
| 高刷新率与动画流畅度 | 部分可用 | 内屏默认 120 Hz 零拷贝（6 个画布槽位）；修复跨帧栅栏追逐后打开/退出缩放动画约 54–59 fps、主屏落定与合成滚动约 95 fps；不宣称全局 120 fps，动态刷新率未实现。 |
| 自动亮度 | 暂不支持 | 传感器协处理器已能读出环境光数据，尚未接入系统自动调光。 |
| 外屏显示与触摸 | 部分可用 | 外屏原始帧缓冲显示（合盖时钟）与 FTM5 触控芯片状态事件已在无人值守轮闭环；外屏完整 iPadOS 界面与手指触控坐标尚未完成。 |
| 折叠与内外屏切换 | 部分可用 | 日用默认开启合盖跟随模式（模拟合盖熄灭内屏并点亮外屏时钟已闭环）；真实开合自动切屏待在场验收。 |
| 电源键 | 部分可用 | 短按熄屏/亮屏已在日用默认配置连续 20/20 轮无人值守通过（待人工看屏与唤醒触控复核）；长按 3 秒热复位退出当前系统。 |
| 音量键 | 待确认 | 实体按键调节音量待随声音主线一并在场验证。 |

**网络与连接**

| 功能 | 适配情况 | 用户可感知的表现 |
| --- | --- | --- |
| Wi-Fi 选网与联网 | 已可用 | 可在系统设置中选择已测试的 WPA2 / 开放 Wi-Fi、输入密码并通过 DHCP 联网访问 HTTPS。 |
| 记住 Wi-Fi 并自动连接 | 已可用 | 已保存的网络在开机或重新启用后可以自动加入。 |
| 关闭、重新开启 Wi-Fi | 已可用 | 已确认关闭后重新开启可清理旧路由/DNS 并再次联网。 |
| 2.4 GHz / 5 GHz Wi-Fi 切换 | 已可用 | 已测试网络的 2.4 GHz 与 5 GHz 不同 BSSID 之间可双向重连并联网。 |
| Wi-Fi 待机与连续使用 | 部分可用 | 25–28 分钟浸泡及跨 10 次熄屏/亮屏保持不断线、零丢包已通过；全天使用、跨不同子网和自然租期续租仍待验证。 |
| 更多 Wi-Fi 类型 | 待确认 | WPA3、企业认证和 6 GHz 网络尚未确认支持。 |
| 移动数据 | 暂不支持 | 基带协处理器已在离线模式（无射频）下完成初始化并公布 45 个 QMI 服务、应答 SIM 卡槽查询；插卡联网尚未启用。 |
| 电话与短信 | 暂不支持 | 尚不能拨打、接听电话或收发短信。 |
| 蓝牙及蓝牙外设 | 部分可用 | 默认开启蓝牙，设置页面可打开蓝牙开关并扫描列出附近设备；配对、连接与蓝牙音频尚未验证。 |

**电池、待机与声音**

| 功能 | 适配情况 | 用户可感知的表现 |
| --- | --- | --- |
| 电量显示 | 已可用 | 右上角状态栏与设置页面显示实际电池电量，读数与 Android 一致。 |
| 充电状态显示 | 已可用 | 插拔电源时充电状态会随之变化；快充协商与完整充放电曲线仍待确认。 |
| 设置中的电池页面 | 部分可用 | 页面可以正常打开；电池健康子页面仍会转圈，长期用量图表尚未确认。 |
| 锁屏、熄屏与唤醒 | 部分可用 | 内屏熄屏/亮屏与熄屏停触控已在日用配置下连续 20/20 轮稳定通过；整机深度平台休眠尚未实现。 |
| 省电待机与续航 | 部分可用 | 熄屏时默认下线 CPU 2–7、压低 GPU 至 220 MHz 并启用 Wi-Fi 802.11 省电，纯电池熄屏电流降至约 422 mA；完整系统睡眠续航仍待实现。 |
| 自动温控 | 已可用 | 日用默认开启两组 TSENS 采样与逐级压频/释放（CPU 90 °C / GPU 85 °C 阈值），持续负载下可稳定压制温升。 |
| 扬声器播放声音 | 暂不支持 | 音频 DSP 连续流与双 CS35L41 功放静音数据通路已打通（引脚采样确认音频数据送达功放）；实际外放试听待在场验收。 |
| 麦克风与录音 | 暂不支持 | 录音数据通路尚未调通。 |

**应用与其他日常功能**

| 功能 | 适配情况 | 用户可感知的表现 |
| --- | --- | --- |
| 设置、备忘录、时钟、天气等系统应用 | 部分可用 | 设置与时钟正常打开；备忘录修复沙盒扩展令牌后不再闪退且支持热启动；天气因缺少 FairPlay 签名仅显示城市名而无温度预报。 |
| 照片应用 | 部分可用 | 已能启动并进入初始界面；查看照片、相册、搜索和编辑仍待人工进一步确认。 |
| 浏览器上网 | 部分可用 | Safari 可打开公网 HTTPS 网页（修复 WebKit GPU 256 MiB 地址窗口后百度等页面正常显示）及无 DRM 静音视频；地址栏输入跳转与有声播放仍待完善。 |
| 中文、英文输入 | 已可用 | 修复键盘布局路径并采用 `iPad7,12` 身份后，系统原生中英文（含拼音）软键盘可正常弹出与输入。 |
| 应用切换与多任务 | 部分可用 | 应用冷热启动、后台保活切换及上滑返回动画已验证无槽位耗尽；分屏等复杂多任务布局待人工确认。 |
| 数据保存与时区 | 部分可用 | 可写 Data 卷跨重启保留，启动参数 `pong_tz` 可设置系统时区（已验证北京时间）；长期使用与异常断电边界仍待观察。 |
| 相机、拍照与录像 | 暂不支持 | 四颗摄像头传感器芯片 ID 已在 iPadOS 下只读应答，尚未实现取景与拍照录像。 |
| 动态壁纸 | 暂不支持 | 为避免与桌面合成器争抢 GPU 资源，壁纸扩展默认禁用 GPU。 |
| Apple 账号、应用商店与第三方应用 | 待确认 | 登录、安装和各第三方应用兼容性尚未形成完整验证结果。 |
| 消息推送与后台接收 | 待确认 | 日常使用和熄屏后的消息推送接收尚未验证。 |
| 自动旋转、定位等功能 | 部分可用 | 开启可选参数 `zizhan_slpi=4` 后传感器协处理器可与音频 DSP 共存并以 52 Hz 上报加速度计，倒置 180° 旋转已确认生效；横屏布局与轴向对应待手持复核（默认关闭，见[待人工验证清单](progress/HUMAN_CHECKLIST.md)），GNSS 定位未实现。 |
