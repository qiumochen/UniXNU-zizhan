# zizhan 电池（ADSP 电池管理）接入 — 2026-11-01

## 结论
ADSP（音频 DSP，高通的电池/充电管理在它上面跑）在 iOS 内核下成功启动，经 PMIC GLINK 读到电池，`PongBattery`（IOPMPowerSource）已发布给 iOS。
g206 读数与安卓 sysfs 一致：电量 100 %、4444 mV、充电 426 mA、34.40 °C、满充 3507 mAh / 设计 4500 mAh、循环 907 次、USB 在线、正在充电。
**还没人眼确认**：状态栏电池图标、设置 › 电池、拔插充电器的变化 → 第 6 节。

## 1. 起点
- 代码早已在树里：`drivers/PongPower`（从 UniXNU-pong（Nothing Phone 2，同为 SM8475）移植；ADSP PAS1 启动、SMEM/SMP2P/GLINK、`ShengBattmgr` 协议、`PongBattery`）。
- zizhan 一直关着：`ci_boot_ufs.sh` 写死 `pong_adsp=0`（"zizhan hardware differs from Pong"）；而且 PongPower 只在 `CONFIG_XNU_PONG_WIFI=y` 时才链接。
- 参考：UniXNU-sheng（小米 SM8550）`package/ShengBattmgr.c`、`porting.toml` power 节（"Battery properties after 11 are shifted by one"）。

## 2. 与 Pong 的硬件差异（安卓 live DT：`/sys/firmware/fdt` → `device/dts/zizhan-live-android.dts`）
| | Pong | zizhan |
|---|---|---|
| ADSP carveout（adsp_region） | 0x85700000 + 0x2800000 | **0x9fd00000 + 0x3100000** |
| SMEM / TCSR mutex / IPCC / AOSS / RSC DRV2 / cmd-db | 0x80900000 / 0x1f43000 / 0xed18000 / 0xc300000 / 0x17a20000 / 0x80860000 | 相同 |
| 固件 | adsp.mbn | `/vendor/firmware_mnt/image/adsp.mdt + b00..b25`（modem 分区 FAT），合并后 22.8 MB，加载跨度正好 0x3100000 |
| 电池属性编号 | QTI 标准 | 小米：12 起后移一位（温度 13、电荷计数 15、循环 16、设计 17、满充 18、充满时间 20、放完时间 21）；温度单位已是 0.01 °C |

## 3. 改动（UniXNU-zizhan，镜像在 device/）
- `drivers/PongPower/PongAdsp.cpp`：carveout 改为 zizhan 值；survey 结果打一行 IOLog。
- `drivers/PongPower/PongPower.cpp`：`pong_adsp=1` 真正只做映射 + 调查（之前 1 不进入）；2 才启动 DSP 与电池。
- `drivers/PongPower/ShengBattmgr.c`：小米属性编号；温度不再 ×10。
- `drivers/PongPower/PongBattery.cpp`：每次刷新打一行读数（电量、mV、mA、温度、标志、USB、满充、设计、循环）。
- `drivers/PongPower/PongRpmh.cpp`（新）：不编 WiFi 时提供共享 RPMh 投票（APSS DRV2 active TCS4）与 SMMU 租约锁，代码取自 PongWifiPlatform.cpp。
- `scripts/build-pong-power-native.py`：没有 Pong 的 tfa98xx.cnt 时生成空功放表（zizhan 不开音频）；无 WiFi 时把 PongRpmh.cpp 与 sheng `QcomRpmh.c` 编进来。
- `CONFIG_XNU_PONG_POWER`（`configs/zizhan_ipados18_gpu_defconfig` = y）：`build-xnu-ipados18.sh` 三处条件、`build-pong-platform-macos.py` 的 `-DXNU_PONG_POWER`、`ArmDTPlatform.cpp` 调用 `pong_power_start_optional`，均与 WiFi 解耦。
- `src.noindex/ci_boot_ufs.sh`：`pong_adsp=${ADSP:-0}`（环境变量 ADSP=1/2 打开；boot-arg 先到先得）。
- 固件：`tools/mac/mdt2mbn.py`（mdt + bNN → mbn）、`tools/mac/fw-refresh.sh TAG MBN`（放进 OS 镜像 `/pong/firmware/adsp.mbn`，部署同 ui-refresh）。已部署 `fw-refresh.sh g204`。固件不进 git。

## 4. 轮次
| 轮 | 参数 | 结果 |
|---|---|---|
| g202 | ADSP=1 | 没有 PongAdsp 行：PongPower 根本没链接（只随 WiFi） |
| g203 | ADSP=1（PONG_POWER 链接后） | survey：slave-kernel 无（DSP 没跑）、SMEM 分区在、GLINK 478/479 有引导程序残留、AOSS 邮箱在 |
| g204 | ADSP=2 | **阶段 1→13 全过**（固件、SMP2P、门铃、QMP load_state、rails、加载、PAS 认证启动、ready、GLINK、通道）；电池发布 100 % 4443 mV，温度 0 |
| g205 | + 小米属性编号 | 满充 3501 / 设计 4500 / 循环 907 与安卓一致；温度仍 0（×10 超范围） |
| g206 | + 温度不 ×10 | 34.40 °C；全部读数与安卓一致 |

## 5. 未做 / 风险
- `ADSP` 还没设为默认（等用户确认）；要默认就把 `ci_boot_ufs.sh` 的 `${ADSP:-0}` 改成 2。
- 充电本身由 ADSP 固件负责（与 sheng 一致：不写充电限值）。拔掉充电器、低电量等变化还没观察。
- 音频仍关（`pong_audio=0`）：zizhan 的功放不是 Pong 的 TFA9873。
